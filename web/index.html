計算方法と実装を見る

bp（basis point）は金利差の単位で、1 bp = 0.01 percentage pointです。4.60%から4.69%への変化なら +0.09 percentage point = +9 bpです。

画面は保存済みsnapshotだけを読みます。比較時はPyodide Web Workerがこのrepositoryの code/static_bi.py をブラウザ内で実行します。金融計算式をJavaScriptへ複製せず、出典・観測期間・取得時刻を画面に残します。
